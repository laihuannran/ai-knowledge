# 零基础阅读顺序设计

用户已要求按小白、关联、浅到深调整目录和查看顺序，并授权直接执行。

采用双层阅读：全书按概念依赖重新组织，另以明确的入门主线连接概念入口。首页优先主线，目录和专题页展示同一份路线。文章同时保留主线下一节与全书上一篇/下一篇，文字明确区分。

全书阶段：认识概念与知识库 → Agent、工具、框架和多模态应用 → 模型内部、推理设施、评测、网关、API、训练与系统架构 → 自我改进研究。训练数学不作为入门门槛；具体工具在对应原理之后。技术专题按新全书位置排序。

以 content/book.json 为唯一顺序来源，保留所有153篇和既有篇章锚点。严格校验每篇前置在全书更早位置；前置有误时按实际机制调整，不为通过检查删除必要依赖。小白主线需唯一、按全书顺序，且选择的课不依赖尚未讲解的主线概念。新增UI沿用当前书籍样式。

验证包括完整构建、目录覆盖、前置顺序、主线唯一性与顺序、主线导航目标、既有链接、手机和桌面阅读及发布后文件比对。
