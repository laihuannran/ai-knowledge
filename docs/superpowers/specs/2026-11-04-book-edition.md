# 图解 AI 教程：书籍版

用户已确认把每个主题深化成系列，并明确要求调研主流/高关注 GitHub 技术栈。延续不用编程、公开 GitHub Pages 和原站的授权。

成品由书籍首页、分篇/分章目录、长文系列、技术栈图谱、项目比较和资料书架构成。保留已有60篇及URL，短文明确标记概念入门；新增26篇机制和案例长文，单篇至少1400正文字符（包含标点与英文），不用通用句凑字。正文应有足够的独立章节、多个真实概念图或表格，能解释流程、边界和取舍。完整目录覆盖每个既有专题，不用新增文章数量冒充完整性。

研究官方文档及GitHub，项目清单核验仓库、定位、许可、star快照与日期，无法获取不编数字。学习资料优先官方、原始材料和高关注原创课程，注明用途、难度、许可与访问日期。采纳教学组织方式和可核实事实，原创重写；只有许可证明确允许才转载署名，不整篇搬运不明许可内容。Star只表示关注度，不是质量证明。

首页采用墨绿与纸张色的书籍编辑风格，提供从头阅读、总目录、技术栈地图和搜索。目录有篇章编号、章摘要、入门/深入标记和关联顺序。文章提供所在篇章、系列定位、下一章和上下篇。移动端可折叠目录、图表独立滚动，键盘可访问。
